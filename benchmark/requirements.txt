# BioLatent benchmark — main environment
#
# Versions are the final probe/release environment, on Python 3.11.15. Each
# neural matrix sidecar separately records the runtime that produced that
# immutable cached embedding. Versions are pinned rather than bounded because probe scores
# are sensitive to solver defaults: scikit-learn has changed LogisticRegression
# and Ridge convergence behaviour across minor releases, and a different
# version can move a ROC-AUC in the third decimal without any error.
#
# MoLFormer-XL does NOT run here. It needs transformers >= 5, which the rest of
# the pipeline is not pinned to; see setup_molformer_env.sh. Uni-Mol and the
# MolCLR/GROVER graph adapters also use isolated compatibility environments;
# their interpreters and official source trees are documented in README.md.
