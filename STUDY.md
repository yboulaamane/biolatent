# BioLatent frozen-embedding study

**Study snapshot:** 2026-09-14
**Embedding protocol:** v2 · **Probe protocol:** v4 · **Inference protocol:** v4

This document describes the measured benchmark generated by `benchmark/`.
It is separate from the literature registry: registry values were reported by
different papers under different protocols and must not be merged with these
results.

## What is measured

BioLatent measures how much task information is accessible to one standard
linear probe from a frozen representation. It does not measure an intrinsic or
universal representation quality. Each compatible model is embedded once,
then every model in a modality receives the same regularisation grid,
cross-validation rule, final fit, metric, and seed.

The release contains nine tasks, 18 distinct representations, and 68 compatible
model-task cells. Missing cross-modality cells are absent rather than imputed.
A fixed one-hidden-layer MLP is reported only as a diagnostic and is never used
for ranking or significance claims.

## Data provenance

All task inputs and labels come from externally published datasets. The local
files were compared with fresh upstream copies, and the exact checks and local
SHA-256 values are recorded in `DATA_PROVENANCE_AUDIT.md`.

The measured pipeline contains no random Gaussian projection, fabricated data
fallback, placeholder embedding, or invented score. Classical representations
are deterministic descriptors; neural representations are outputs of pinned
public checkpoints. A failed or missing cell remains missing, and the release
validator rejects an incomplete grid.

## Frozen-embedding protocol

- Neural checkpoints and their source repositories are pinned to immutable
  revisions and weight hashes.
- Transformer outputs are mean-pooled over attention-mask tokens after removing
  tokenizer-designated special tokens.
- Uni-Mol v1 uses its official molecular checkpoint and mean-pools valid atom
  representations. MolCLR uses the official pretrained GIN graph encoder and
  global mean pooling. GROVER Base and Large use the official `both`
  fingerprint, which concatenates atom- and bond-view graph representations.
- MolCLR is N/A on ClinTox because its official featurizer cannot represent all
  dataset structures. No row was removed, rewritten, or imputed to create a
  nominally complete result.
- Maximum token length is 256 for molecules and 512 for protein/genomic inputs.
- Raw protein and DNA sequences are capped at 510 characters before
  tokenisation. ProtBERT applies its documented `U/Z/O/B` to `X` mapping.
- Every matrix has a sidecar containing the checkpoint, revision, input hash,
  matrix hash, shape, dtype, pooling, truncation, device, precision policy, and
  software runtime.
- Every reported score stores the SHA-256 of the exact matrix used to compute it.

The protein length limit is a real constraint. Full-sequence 3-mer features do
not share transformer truncation, and results must be interpreted conditional
on this chosen input budget.

## Probe and inference protocol

The ranked probe is L2-regularised logistic regression for classification and
ridge regression for regression. Features are standardised inside each
training-only cross-validation fold; the selected hyperparameter is then fit on
all non-test labels. Regularisation search is capped at a deterministic 6,000
rows on larger tasks. Binary tasks use ROC-AUC, ClinTox and DeepLoc use macro
ROC-AUC, and regression tasks use Spearman rho.

For every task, the comparison reference is selected on validation data rather
than on the test score. Test-set difference intervals use a paired bootstrap.
Molecular resampling units are Murcko-scaffold clusters; protein and genomic
units are individual items. Two-sided p-values use 2,000 paired randomisation
draws. The primary Holm correction spans every reference comparison across the
nine-task study; task- and modality-level adjustments are retained as
sensitivity analyses. Consecutive ESM-2 scale steps form a separate
pre-specified family.

“Not resolved” means the study-wide test did not distinguish a model from the
validation-selected reference. It does not mean the models are equal.

After the study-wide Holm correction, 14 of 47 molecular comparisons, all 10
protein comparisons, and 0 of 2 genomic comparisons were resolved (24 of 59
overall). These counts describe this task and model roster, not an intrinsic
difference between modalities. The validation-selected reference also differs
from the numerical test best on several tasks, which is why the test best is
reported descriptively rather than reused as the comparator.

The pre-specified ESM-2 ladder improved at all three scale steps on DeepLoc. On
Fluorescence, 8M to 35M and 150M to 650M improved, while 35M to 150M regressed;
all six step tests survived their ladder-level Holm correction. Model scale is
therefore task-conditional even within this fixed protocol.

## Split and sample-size sensitivity

`results/split_seed_sensitivity.json` redraws each molecular scaffold split at
five pre-specified seeds and refits the linear probes. This quantifies how much
scores and numerical ordering depend on the fixed split; it is not a second
leaderboard.

`results/resolution_curves.json` repeatedly subsamples the saved fixed-test
predictions without replacement. Molecular subsets retain whole scaffold
groups. These curves show empirical stability conditional on the observed test
set. Test size can contribute to precision, but task structure, label noise,
dependence, and effect size also matter; the analysis does not make a causal
claim about modality or sample size.

## Pretraining input-exposure proxies

The exposure audit does not test downstream label leakage. It reports input
familiarity proxies against random 200,000-molecule PubChem and ZINC samples,
Swiss-Prot homology, or known reference-genome construction. GROVER's declared
ChEMBL pretraining exposure is retained as unmeasured rather than being treated
as zero. Molecular “any” fractions are unions of exact identity, ECFP4 Tanimoto
at least 0.9, and shared Murcko scaffold; the JSON retains each measure
separately.

membership. High fractions can affect interpretation, but neither high nor low
fractions establish whether a checkpoint memorised a downstream label.

## Release artifacts and reproduction

The website imports the public JSON files directly at build time:

- `results/benchmark_results.json`
- `results/paired_comparisons.json`
- `results/exposure_report.json`
- `results/split_seed_sensitivity.json`
- `results/resolution_curves.json`
- `results/run_manifest.json`
- `results/predictions/*.npz`

Reproduce and validate in this order:

```bash
python benchmark/download_real_datasets.py
python benchmark/run_study.py --embeddings-only
python benchmark/run_study.py
python benchmark/paired_test.py
python benchmark/run_leakage.py --sample 200000
python benchmark/resolution_analysis.py
python benchmark/split_sensitivity.py
python benchmark/run_study.py --refresh-metadata
python benchmark/validate_release.py --full-hash
python paper/generate_manuscript.py
```

The manifest must be refreshed after all analyses because it hashes every
public artifact and saved prediction. The full release gate reloads the real
datasets, verifies split disjointness, hashes every embedding matrix, checks
all checkpoint/input/protocol links, recomputes metrics from saved predictions,
and verifies manifest hashes.

## Limitations

- The model roster is broader but intentionally non-exhaustive and does not
  support universal architecture-family rankings.
- One checkpoint layer, pooling rule, truncation budget, probe family, and
  regularisation grid define the estimand.
- Bootstrap intervals condition on a fixed split; five molecular resplits are
  sensitivity evidence, not a full hierarchical uncertainty model.
- DeepLoc uses one fixed assignment of the published homology folds rather than
  a five-fold average.
- Fluorescence variants are related, while inference resamples individual
  variants; dependence may therefore remain under-modelled.
- Exposure audits use proxies rather than exact private checkpoint corpora.
- Literature registry values remain heterogeneous even after source auditing.

The defensible output of BioLatent is a provenance-linked measurement with an
uncertainty statement—not a context-free rank.
